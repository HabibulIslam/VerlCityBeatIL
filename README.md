Operating under the administrative umbrella of **House of Jennifer, Inc.**

## 📂 Website Architecture & Pages

- **`index.html`** — Comprehensive homepage featuring top utility bar, hero with Detroit community embrace imagery, trust badges, founder spotlight, living options, 4-phase reentry pathway, competencies & differentiators matrix, facility showcase, resident testimonials, FAQ accordion, online intake form, and footer.
- **`pages/about.html`** — In-depth mission, founder story of Jennifer Moore, House of Jennifer, Inc. umbrella, core values (Respect, Accountability, Compassion, Integrity, Quality, Community Reinvestment).
- **`pages/programs.html`** — Detailed breakdown of Transitional Housing, Sober Living Support, Workforce Readiness, Case Management, and Daily Resident Schedule.
- **`pages/capability-statement.html`** — Dedicated, audit-ready Capability Statement formatted for government contracting officers, MDOC agents, and institutional partners with one-click Print / Save PDF capability.
- **`pages/resident-application.html`** — Multi-step online intake and referral application for MDOC parole agents, case workers, sponsors, and returning citizens.
- **`pages/contact.html`** — Direct contact information, hours, facility address, and interactive schedule a tour / consultation booking.

## 💻 Local Testing & Preview

This website is built with pure, high-performance HTML5, Vanilla CSS3, and modern JavaScript with zero external build step dependencies. It works immediately in any web browser:

1. Double-click `index.html` or open `file:///.../index.html` in Chrome/Edge/Firefox.
2. Or serve locally with any static web server (e.g. Python or PowerShell HTTP Listener):
   ```powershell
   # In PowerShell:
   Start-Process index.html
   ```
